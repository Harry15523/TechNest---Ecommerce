Our story

About TechNest

A fictional electronics retailer created for a web development assignment.

Our purpose

TechNest helps customers understand and compare practical technology products. The design uses plain language, clear pricing and simple navigation.

Design approach

The website is mobile-first. CSS Grid and Flexbox adapt the layout for wider screens. JavaScript uses DOM events to power product search, details, cart updates and form validation.

Project technologies

  • Semantic HTML5
  • Custom mobile-first CSS
  • Vanilla JavaScript
  • LocalStorage for cart persistence
  • No frameworks or external libraries
