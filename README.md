## Project overview
TechNest is a front-end electronics store created using semantic HTML, custom CSS and vanilla JavaScript DOM manipulation. No back-end, framework or external library is required.

## Features
- Home, products, cart, about and contact pages.
- 12 product cards with images, categories, descriptions and prices.
- Product search and category filtering.
- Product detail dialog.
- Add, remove, increase and decrease cart items.
- Dynamic subtotal, delivery and total calculation.
- Cart persistence using localStorage.
- Contact and checkout form validation.
- Mobile-first responsive design.
- Accessibility features including a skip link, labels, alt text, visible focus and live regions.
- SEO metadata and a simple local page-view counter stored in localStorage.

## How to run
1. Download or unzip the project folder.
2. Open the project in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. The root file redirects to `Pages/index.html`.

## Folder structure
- `Pages/` - website pages.
- `css/` - external stylesheet.
- `js/` - JavaScript functionality.
- `media/` - local product images.
- `evidence/` - Lighthouse evidence and testing notes.

## Testing checklist
- Add several products to the cart.
- Refresh the page and confirm the cart remains.
- Increase, decrease and remove quantities.
- Test search and category filtering.
- Submit incomplete forms and check error messages.
- Resize the browser at mobile, tablet and desktop widths.
- Check the browser console for errors.
