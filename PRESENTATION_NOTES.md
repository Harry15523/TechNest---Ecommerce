# 10-Slide Presentation Plan and Speaking Notes

## Slide 1 - Project introduction
TechNest is a responsive front-end electronics store. I built it with HTML, CSS and JavaScript only. The purpose is to simulate a simple online shopping experience without a back-end.

## Slide 2 - Requirements and target users
The site includes five main pages and twelve products. Customers can browse, search, view details and manage a shopping cart. The design targets mobile, tablet and desktop users.

## Slide 3 - File structure
Show the Pages, css, js, media and evidence folders. Explain that separating files makes the project organised and maintainable. The root index file redirects users to the home page.

## Slide 4 - HTML structure
Show semantic elements such as header, nav, main, section, article, aside and footer. Explain how labels, headings and alternative text improve structure and accessibility.

## Slide 5 - CSS and responsive design
Demonstrate the mobile layout first. Then resize to tablet and desktop. Explain that CSS Grid, Flexbox, fluid widths and media queries adapt the page.

## Slide 6 - Product listing and DOM interaction
Show the twelve products. Demonstrate the search box and category filter. Explain that JavaScript reads the input, checks each card and changes its hidden property.

## Slide 7 - Shopping cart
Add two products. Increase and decrease quantities. Remove an item. Explain that the cart is stored in localStorage and totals are recalculated using JavaScript.

## Slide 8 - Forms and validation
Open the contact or checkout form. Submit empty data to show errors, then submit valid data. Explain that checkValidity and DOM messages provide immediate feedback.

## Slide 9 - Accessibility, SEO and testing
Show the skip link, keyboard focus, labels, alt text and contrast. Show meta description and Open Graph tags. Insert the before-and-after Lighthouse screenshots from the evidence folder.

## Slide 10 - Reflection and conclusion
Summarise how the project meets LO1 to LO4. Mention one challenge, such as keeping cart data consistent. Explain that testing and reusable functions improved the final website.
