# Final Completion Steps

The website code, local images, README and presentation notes are complete. The following tasks must be done personally before submission.

## 1. Personalise the work
1. Open README.md.
2. Add your full name, student ID and module code.
3. Change any product names, wording or colours you want so the project reflects your own decisions.
4. Read every function in js/script.js and practise explaining it.

## 2. Test the website
1. Install Visual Studio Code.
2. Open the project folder.
3. Install the Live Server extension.
4. Right-click index.html and select Open with Live Server.
5. Test every navigation link, button, filter, form and cart control.
6. Press F12 and confirm there are no red console errors.

## 3. Produce Lighthouse evidence
Follow evidence/INSTRUCTIONS.md and save four screenshots in the evidence folder.

## 4. Upload to GitHub
1. Sign in at GitHub and click New repository.
2. Name it technest-ecommerce.
3. Keep it Public unless your tutor says otherwise.
4. Click Create repository.
5. Select uploading an existing file.
6. Drag all project folders and files into the upload area.
7. Add the commit message: Initial TechNest e-commerce project.
8. Click Commit changes.
9. Open Settings, then Pages.
10. Under Build and deployment choose Deploy from a branch.
11. Select main and /(root), then Save.
12. Wait a few minutes and test the published link.

## 5. Record the presentation
1. Create 10 slides using PRESENTATION_NOTES.md.
2. Add your own screenshots of the website and code.
3. Record an 8-10 minute presentation.
4. Demonstrate the live website, not only slides.
5. Keep the final video under 10 minutes.

## 6. Submit to Moodle
Upload the complete zipped project, the recorded presentation, and any item requested separately by your tutor. Check the uploaded files open correctly before the deadline.
